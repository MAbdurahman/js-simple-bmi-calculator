# js-simple-bmi-calculator

#### <p>A simple, responsive BMI calculator built with custom radio inputs, floating-label number fields, and 3D-style buttons. Calculates BMI from user height and weight, displays the result with health-category feedback, and features a clean, interactive UI.</p>

## Features
- HTML5
- CSS3
- JavaScript
- Responsive Design
- SweetAlert One
